# README artwork

## Banner

The English and Korean READMEs share [banner.svg](banner.svg), a 1360 × 270
vector image displayed at 680 pixels wide. The SVG is the editable source.
The relative image path follows the branch viewed on GitHub.

The banner follows the [Chemvas](https://github.com/dhsohn/Chemvas) visual family:
a dark green background (`#123e39`), teal bottom rule (`#0d9488`), white title,
pale subtitle (`#c5e9df`), DejaVu Sans typography, and matching spacing.
The white orca within a hexagon uses the approved ORCA_auto identity.
The banner places the standalone mark directly on its background, without the
rounded-square icon tile.

Keep the title and subtitle readable at the README display size. The SVG is
self-contained, with no scripts, external fonts, or linked images. It uses
locally installed DejaVu Sans or the viewer's sans-serif fallback.

## App icon

[icon.png](icon.png) is the approved square logo artwork: a white orca inside a
hexagonal outline on a teal rounded square, with a white exterior background.
It is retained separately for icon use and is not the README header.
The banner and icon are ORCA_auto branding, not the ORCA engine logo.
