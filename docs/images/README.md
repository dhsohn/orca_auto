# README artwork

## Banner

The English and Korean READMEs share [banner.svg](banner.svg), a 1360 × 270
vector image displayed at 680 pixels wide. The SVG is the editable source.
The relative image path follows the branch viewed on GitHub.

The banner shares the [Chemvas](https://github.com/dhsohn/Chemvas) visual palette:
a dark green background (`#123e39`), teal bottom rule (`#0d9488`), white title,
pale subtitle (`#c5e9df`), DejaVu Sans typography, and matching spacing.
The white orca inside a hexagon is placed directly on the banner background without the rounded-square icon tile.

Keep the title and subtitle readable at the README display size. The SVG is
self-contained, with no scripts, external fonts, or linked images, using
locally installed DejaVu Sans or the viewer's sans-serif fallback.

## App icon

[icon.png](icon.png) is the square app icon: a white orca inside a hexagonal
outline on a teal rounded square with a white exterior background.
The banner and icon are ORCA_auto project branding, not the ORCA engine logo.
