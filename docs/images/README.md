# README artwork

## Logo

The English and Korean READMEs display [icon.png](icon.png) at 180 pixels wide.
This PNG is the approved logo artwork: a white orca inside a hexagonal outline
on a teal rounded square, with a white exterior background. It follows the
visual family of Chemvas and LLMdocx. This is the ORCA_auto logo, not the
ORCA engine logo. The relative image path follows the branch viewed on GitHub.

## Banner

The earlier [banner.svg](banner.svg) is retained as a 1360 × 270 vector asset,
designed for display at 680 pixels wide. The SVG is the editable source;
no image-generation script or runtime dependency is needed.

The banner follows the [Chemvas](https://github.com/dhsohn/Chemvas) visual family:
the same dark green background (`#123e39`), teal rule (`#0d9488`), pale subtitle
(`#c5e9df`), DejaVu Sans typography, spacing, and hexagonal outline. The queue
lines and execution node distinguish ORCA_auto; the node and `_auto` use
`#57cabc` for contrast against the dark background. This is an ORCA_auto mark,
not the ORCA engine's logo.

Edit the SVG directly and keep its text readable at the README's display size.
It is self-contained, with no scripts, external fonts, or linked images. It
uses locally installed DejaVu Sans, or the viewer's sans-serif fallback.
